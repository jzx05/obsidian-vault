# ACT — 动作分块变换器

> [!abstract] 核心思想
> 用 CVAE + action chunking，把“每步预测一个动作”改成“一次预测未来 k=100 步动作”，用隐变量 z 捕捉人类演示的多模态；推理时 z=0，一次前向出整段动作。

> [!tip] Eureka Moment
> 高频控制不一定需要高频决策：一次生成 100 步，再用 temporal ensemble 平滑拼接，既降低 compounding error，又把策略推理频率降到约 0.5 Hz。

## 🏗️ 架构与信息流

```text
当前观测（单帧）
4 × RGB (480×640)              qpos [B,14]
      │                            │
 ResNet-18                     Linear → 512
      │ 15×20×512
      ▼
 300 token/相机 × 4 = 1200
      │
      ├── qpos token (1)
      └── z token (1)  ←── z [B,32] ──Linear→512
      ▼
 1202 × 512
      │
      ▼
Transformer Encoder (4 层)
      │ memory
      ▼
Transformer Decoder (7 层)
      ▲
      │
100 个 learned queries
      │
      ▼
100 × 512 → Linear → 100 × 14 动作
```

训练时另有一条 CVAE 编码器支路：

```text
[CLS] + qpos + 真实动作块 (102 token)
              │
              ▼
   BERT-like Transformer Encoder (4 层)
              │ 取 [CLS]
              ▼
        μ, logvar (各 32) → 采样 z
```

### 系统组件对比

| 模块 | 输入 | 输出 | 频率/时序 | 训练/推理差异 |
|------|------|------|-----------|----------------|
| 观测编码器 | 4 路 RGB（当前单帧）+ qpos | 1200 图像 token + 1 qpos token | 每个决策步 | ResNet-18 共享主干；4 层 Transformer encoder |
| CVAE 编码器 | qpos + 真实动作块 + [CLS] | μ, logvar（各 32） | 仅训练 | BERT-like 4 层；**不输入图像**，推理时丢弃 |
| 动作解码器 | 1202 memory token + 100 个 query | 100 × 14 动作块 | 每个决策步 | 7 层 Transformer decoder；100 个 query 并行输出 |
| 时间集成 | 多个重叠动作块 | 当前步动作 | 每个控制步 | 指数加权平均，不参与训练 |

## 🔑 关键机制

- **动作分块（Action Chunking）**：一次预测 k=100 步，而不是单步。决策频率从 50 Hz 降到约 0.5 Hz，减少 compounding error，也让模型隐式学习子任务结构。
- **CVAE 隐变量**：训练时 encoder 看 qpos + 真实动作块，输出 μ/logvar，采样 z；decoder 在 z 条件下重建动作，从而覆盖“同一观测下多种合理做法”。
- **推理时 z=0**：不采样、不用 encoder，直接取先验均值，保证动作确定性，避免同一观测下随机切换风格。
- **L1 重建损失**：论文 Algorithm 1 写 `MSE(â, a)`，但正文和官方代码实际使用 **L1**（`F.l1_loss`），作者认为 L1 对动作序列建模更精确。
- **z 是 memory token**：z 投影成 1 个 token，和 1200 个图像 token、qpos token 一起进 encoder；不是拼到每个 query 上。
- **时间集成（Temporal Ensemble）**：重叠动作块按指数权重 `w_i = exp(-m·i)` 融合，m=0.01；越新的预测权重越大，用来平滑块与块之间的跳变。

## 📊 关键数据

| 维度 | 数值 |
|---|---|
| 参数量 | 约 80M |
| 动作块 | k=100（50 Hz 下约 2 秒） |
| 观测 | 4 路 480×640 RGB + 14 维 qpos |
| 动作空间 | 14 维双臂绝对关节位置（7+7） |
| 训练数据 | 每个任务约 50 条人类演示（Thread Velcro 100 条） |
| 训练成本 | 单张 11G RTX 2080 Ti，约 5 小时/任务 |
| 推理速度 | 约 0.01 秒/次前向 |
| 决策频率 | 每 100 步预测一次，约 0.5 Hz；底层执行 50 Hz |

## 🧮 补充：CVAE 损失与推理

### 基本公式

$$
\mathcal{L} = \mathcal{L}_{\text{recon}} + \beta \cdot D_{KL}\big(q_\phi(z \mid s, a) \,\|\, \mathcal{N}(0, I)\big)
$$

ACT 实际使用的重建损失是 L1：

$$
\mathcal{L}_{\text{recon}} = \| a - \hat{a} \|_1
$$

对角高斯的 KL 闭式解：

$$
D_{KL} = -\frac{1}{2}\sum_{j=1}^{D_z}\left(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\right)
$$

推理时：

$$
z = 0,\qquad \hat{a}_{t:t+k} = \mathrm{decoder}(o_t, z)
$$

### 符号说明

| 符号 | 含义 |
|---|---|
| $s$ | 本体感知（qpos，14 维） |
| $a$ | 真实动作块，$k \times 14$ |
| $z$ | CVAE 隐变量，32 维 |
| $\mu, \sigma^2$ | encoder 输出的均值与方差 |
| $\beta$ | KL 权重，ACT 常用 10 |
| $o_t$ | 当前观测（4 路图像 + qpos） |
| $k$ | 动作块长度，100 |

### 直觉

CVAE 把“人类演示的多模态”压进 32 维的 z：同一观测下，左绕和右绕可以对应不同的 z。训练时 encoder 从真实动作里推断 z，decoder 学会在给定 z 时重建动作；KL 项让 z 的分布靠近标准正态，保证推理时 z=0 不会落在无意义的区域。

## 🧩 局限与失败模式

- **单任务策略**：ACT 不是语言条件模型，每个任务单独训练一个策略；换任务要重新采数据、重训。
- **隐空间容量有限**：CVAE 只有 32 维 z，复杂多模态任务可能覆盖不全。
- **KL 坍塌风险**：β 过大时 z 被压成常数，模型退化为确定性回归；β 过小时隐空间不规整，z=0 附近可能没有有效行为。
- **单帧观测**：没有历史帧或记忆，遮挡或快速变化场景下只能依赖当前帧。
- **本体绑定**：14 维双臂关节位置绑定 ALOHA，换机器人要改动作维度与数据。
- **时间集成有滞后**：指数平均会平滑快速修正，极端动态任务可能反应不够快。
