# ACT — 动作分块变换器

> [!abstract] 核心思想
> 用 CVAE + action chunking，把“每步预测一个动作”改成“一次预测未来 k=100 步动作”，用隐变量 z 捕捉人类演示的多模态；推理时 z=0，一次前向出整段动作。

> [!tip] Eureka Moment
> 高频控制不一定需要高频决策：一次生成 100 步，再用 temporal ensemble 平滑拼接，既降低 compounding error，又把策略推理频率降到约 0.5 Hz。

## 🏗️ 架构与信息流

```text
当前观测（单帧）
4 × RGB (480×640)              qpos [B,14]
      │                            │
 ResNet-18                     Linear → 512
      │ 15×20×512
      ▼
 300 token/相机 × 4 = 1200
      │
      ├── qpos token (1)
      └── z token (1)  ←── z [B,32] ──Linear→512
      ▼
 1202 × 512
      │
      ▼
Transformer Encoder (4 层)
      │ memory
      ▼
Transformer Decoder (7 层)
      ▲
      │
100 个 learned queries
      │
      ▼
100 × 512 → Linear → 100 × 14 动作
```

训练时另有一条 CVAE 编码器支路：

```text
[CLS] + qpos + 真实动作块 (102 token)
              │
              ▼
   BERT-like Transformer Encoder (4 层)
              │ 取 [CLS]
              ▼
        μ, logvar (各 32) → 采样 z
```

### 系统组件对比

| 模块 | 输入 | 输出 | 频率/时序 | 训练/推理差异 |
|------|------|------|-----------|----------------|
| 观测编码器 | 4 路 RGB（当前单帧）+ qpos | 1200 图像 token + 1 qpos token | 每个决策步 | ResNet-18 共享主干；4 层 Transformer encoder |
| CVAE 编码器 | qpos + 真实动作块 + [CLS] | μ, logvar（各 32） | 仅训练 | BERT-like 4 层；**不输入图像**，推理时丢弃 |
| 动作解码器 | 1202 memory token + 100 个 query | 100 × 14 动作块 | 每个决策步 | 7 层 Transformer decoder；100 个 query 并行输出 |
| 时间集成 | 多个重叠动作块 | 当前步动作 | 每个控制步 | 指数加权平均，不参与训练 |

## 🔑 关键机制

- **动作分块（Action Chunking）**：一次预测 k=100 步，而不是单步。决策频率从 50 Hz 降到约 0.5 Hz，减少 compounding error，也让模型隐式学习子任务结构。
- **CVAE 隐变量**：训练时 encoder 看 qpos + 真实动作块，输出 μ/logvar，采样 z；decoder 在 z 条件下重建动作，从而覆盖“同一观测下多种合理做法”。
- **推理时 z=0**：不采样、不用 encoder，直接取先验均值，保证动作确定性，避免同一观测下随机切换风格。
- **L1 重建损失**：论文 Algorithm 1 写 `MSE(â, a)`，但正文和官方代码实际使用 **L1**（`F.l1_loss`），作者认为 L1 对动作序列建模更精确。
- **z 是 memory token**：z 投影成 1 个 token，和 1200 个图像 token、qpos token 一起进 encoder；不是拼到每个 query 上。
- **时间集成（Temporal Ensemble）**：重叠动作块按指数权重 `w_i = exp(-m·i)` 融合，m=0.01；论文和官方代码都定义 `w_0` 对应**最旧**的预测，`i` 越大权重越小，用来平滑块与块之间的跳变。

## 🧮 补充：CVAE 损失与推理

### 基本公式

$$
\mathcal{L} = \mathcal{L}_{\text{recon}} + \beta \cdot D_{KL}\big(q_\phi(z \mid s, a) \,\|\, \mathcal{N}(0, I)\big)
$$

ACT 实际使用的重建损失是 L1：

$$
\mathcal{L}_{\text{recon}} = \| a - \hat{a} \|_1
$$

对角高斯的 KL 闭式解：

$$
D_{KL} = -\frac{1}{2}\sum_{j=1}^{D_z}\left(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2\right)
$$

推理时：

$$
z = 0,\qquad \hat{a}_{t:t+k} = \mathrm{decoder}(o_t, z)
$$

### 符号说明

| 符号 | 含义 |
|---|---|
| $s$ | 本体感知（qpos，14 维） |
| $a$ | 真实动作块，$k \times 14$ |
| $z$ | CVAE 隐变量，32 维 |
| $\mu, \sigma^2$ | encoder 输出的均值与方差 |
| $\beta$ | KL 权重，ACT 常用 10 |
| $o_t$ | 当前观测（4 路图像 + qpos） |
| $k$ | 动作块长度，100 |

### 直觉

CVAE 把“人类演示的多模态”压进 32 维的 z：同一观测下，左绕和右绕可以对应不同的 z。训练时 encoder 从真实动作里推断 z，decoder 学会在给定 z 时重建动作；KL 项让 z 的分布靠近标准正态，保证推理时 z=0 不会落在无意义的区域。

## 🧑‍💻 代码实现

### 核心代码：最小 ACT Policy

```python
import torch                     # 张量运算
import torch.nn as nn            # 神经网络模块
import torch.nn.functional as F  # 损失函数

class ACTPolicy(nn.Module):      # ACT 策略网络
    def __init__(                       # 构造函数
        self,                           # self 指针
        state_dim=14,            # 本体感知维度：双臂 7+7
        action_dim=14,           # 动作维度：双臂关节位置
        chunk_size=100,          # 一次预测的未来步数
        z_dim=32,                # CVAE 隐变量维度
        d_model=512,             # Transformer 隐藏维度
        nhead=8,                 # 多头注意力的头数
        enc_layers=4,            # encoder 层数
        dec_layers=7,            # decoder 层数
        dim_feedforward=3200,    # FFN 中间维度
    ):
        super().__init__()               # 初始化 nn.Module
        self.chunk_size = chunk_size     # 保存动作块长度
        self.z_dim = z_dim               # 保存隐变量维度

        # 观测：4 路相机共享 ResNet-18（backbone 省略）
        self.qpos_proj = nn.Linear(state_dim, d_model)  # qpos → 512 维 token

        # CVAE encoder：仅训练时使用
        self.cls = nn.Embedding(1, d_model)             # 可学习 [CLS] token
        self.action_proj = nn.Linear(action_dim, d_model)  # 动作 → 512 维
        self.cvae_encoder = nn.TransformerEncoder(      # BERT-like encoder
            nn.TransformerEncoderLayer(d_model, nhead, dim_feedforward),  # 单层定义
            num_layers=enc_layers,                      # 堆 4 层
        )
        self.latent_proj = nn.Linear(d_model, z_dim * 2)  # [CLS] → μ 和 logvar

        # 观测 encoder + z token
        self.obs_encoder = nn.TransformerEncoder(       # 观测融合 encoder
            nn.TransformerEncoderLayer(d_model, nhead, dim_feedforward),  # 单层定义
            num_layers=enc_layers,                      # 堆 4 层
        )
        self.z_proj = nn.Linear(z_dim, d_model)         # z → 512 维 token

        # action decoder
        self.query = nn.Embedding(chunk_size, d_model)  # 100 个可学习 query
        self.decoder = nn.TransformerDecoder(           # 动作 decoder
            nn.TransformerDecoderLayer(d_model, nhead, dim_feedforward),  # 单层定义
            num_layers=dec_layers,                      # 堆 7 层
        )
        self.action_head = nn.Linear(d_model, action_dim)  # 512 维 → 14 维动作

    def encode_z(self, qpos, actions):                  # CVAE encoder 前向
        """训练时：qpos + 动作块 + [CLS] → μ, logvar"""
        b = qpos.size(0)                                # batch size
        cls = self.cls.weight.unsqueeze(1).expand(-1, b, -1)  # [1,B,D]
        q = self.qpos_proj(qpos).unsqueeze(0)           # [1,B,D]
        a = self.action_proj(actions).permute(1, 0, 2)  # [k,B,D]
        h = self.cvae_encoder(torch.cat([cls, q, a], dim=0))[0]  # 取 [CLS]
        mu, logvar = self.latent_proj(h).chunk(2, dim=-1)  # 拆成 μ/logvar
        return mu, logvar                               # 返回后验参数

    def reparameterize(self, mu, logvar):               # 重参数化技巧
        std = torch.exp(0.5 * logvar)                   # σ = exp(logvar/2)
        return mu + std * torch.randn_like(std)         # z = μ + σ⊙ε

    def decode(self, image_tokens, qpos, z):            # 策略 decoder 前向
        """image_tokens: [B,1200,D]；z 作为 memory token 进入 encoder"""
        b = qpos.size(0)                                # batch size
        q = self.qpos_proj(qpos).unsqueeze(0)           # [1,B,D]
        zt = self.z_proj(z).unsqueeze(0)                # [1,B,D]
        memory = torch.cat([image_tokens.permute(1, 0, 2), q, zt], dim=0)  # [1202,B,D]
        memory = self.obs_encoder(memory)               # [1202,B,D] 融合
        queries = self.query.weight.unsqueeze(1).expand(-1, b, -1)  # [100,B,D]
        out = self.decoder(queries, memory)             # [100,B,D]
        return self.action_head(out).permute(1, 0, 2)   # [B,100,14]

    def forward(self, image_tokens, qpos, actions=None):  # 统一入口
        if actions is not None:                         # 训练模式
            mu, logvar = self.encode_z(qpos, actions)   # 从真实动作推断 z
            z = self.reparameterize(mu, logvar)         # 采样 z
            return self.decode(image_tokens, qpos, z), mu, logvar  # 预测 + 后验
        z = torch.zeros(qpos.size(0), self.z_dim, device=qpos.device)  # 推理 z=0
        return self.decode(image_tokens, qpos, z)       # 确定性预测
```

### 损失函数

```python
def act_loss(pred, gt, mu, logvar, beta=10.0):          # ACT 损失函数
    recon = F.l1_loss(pred, gt)                         # L1 重建损失
    kl = -0.5 * (1 + logvar - mu.pow(2) - logvar.exp()).sum(-1).mean()  # KL 散度
    return recon + beta * kl, recon, kl                 # 总损失 + 两个分项
```

### 训练循环

```python
policy = ACTPolicy().cuda()                              # 策略放到 GPU
optimizer = torch.optim.AdamW(policy.parameters(), lr=1e-4)  # AdamW 优化器

for images, qpos, actions in loader:                     # 遍历训练数据
    images = images.cuda()                               # [B,4,3,480,640]
    qpos = qpos.cuda()                                   # [B,14]
    actions = actions.cuda()                             # [B,100,14]
    image_tokens = backbone(images)                      # [B,1200,512]
    pred, mu, logvar = policy(image_tokens, qpos, actions)  # 前向 + 后验
    loss, recon, kl = act_loss(pred, actions, mu, logvar)  # 计算 L1 + KL
    optimizer.zero_grad()                                # 清空梯度
    loss.backward()                                      # 反向传播
    optimizer.step()                                     # 更新参数
```

```python
@torch.no_grad()                                        # 推理不需要梯度
def act_infer(policy, image_tokens, qpos):               # 单步推理入口
    return policy(image_tokens, qpos)                    # 内部 z=0，输出 [B,100,14]
```

时间集成的核心是指数权重：

```python
def temporal_ensemble(chunks, t, m=0.01):                # 时间集成函数
    """chunks: [(start_t, chunk), ...]；取所有覆盖 t 的预测做加权平均。
    preds 按预测时间从旧到新排列，w_0 对应最旧预测。"""
    preds = [c[t - s] for s, c in chunks if 0 <= t - s < len(c)]  # 覆盖 t 的预测
    if not preds:                                        # 没有可用预测
        return None                                      # 返回空
    w = torch.exp(-m * torch.arange(len(preds), device=preds[0].device))  # 指数权重
    w = w / w.sum()                                      # 归一化
    return (torch.stack(preds) * w[:, None]).sum(dim=0)  # 加权平均
```

> 注意：官方实现的 `exp_weights` 在 `imitate_episodes.py` 里，`w_0` 对应最旧的预测；上面的写法是等价示意，实际接入时对齐索引即可。

## 🧩 局限与失败模式

- **单任务策略**：ACT 不是语言条件模型，每个任务单独训练一个策略；换任务要重新采数据、重训。
- **隐空间容量有限**：CVAE 只有 32 维 z，复杂多模态任务可能覆盖不全。
- **KL 坍塌风险**：β 过大时 z 被压成常数，模型退化为确定性回归；β 过小时隐空间不规整，z=0 附近可能没有有效行为。
- **单帧观测**：没有历史帧或记忆，遮挡或快速变化场景下只能依赖当前帧。
- **本体绑定**：14 维双臂关节位置绑定 ALOHA，换机器人要改动作维度与数据。
- **时间集成有滞后**：指数平均会平滑快速修正，极端动态任务可能反应不够快。
