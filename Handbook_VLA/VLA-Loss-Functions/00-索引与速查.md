## 2. Loss 在 VLA Pipeline 里的挂载位置

```text
Sensors → Encoders → Fusion → Policy Head → Action → Robot
             │           │          │
             │           │          └── action losses
             │           │              BC / GMM / CE / Diffusion / Flow / RL
             │           └───────────── alignment / grounding losses
             └───────────────────────── perception / self-supervised losses
```

| 层级 | 常见损失 |
|---|---|
| Encoder | InfoNCE / CLIP 对齐、深度/姿态监督、MAE、contrastive |
| Fusion | 跨模态对齐（vision ↔ tactile ↔ text）、adapter/LoRA |
| Policy / Action Head | BC、Token CE、GMM NLL、Diffusion ε loss、Flow matching、RL |
| 输出后处理 | 动作平滑、约束/barrier、contact/torque 限制 |

## 3. 统一记号

| 符号 | 含义 | 常见形状 |
|---|---|---|
| `B` | batch size | — |
| `T_obs` | 观测序列长度 | — |
| `T_act` | 动作序列长度 | — |
| `K` | 动作 chunk 长度 / GMM 分量数（按上下文区分） | — |
| `D_a` | 动作维度 | 7（Franka）等 |
| `N_bins` | 每维离散 bin 数 | 256 |
| `a` | 连续动作 | `[B, T_act, D_a]` |
| `a_{t:t+K-1}` | 动作 chunk | `[B, K, D_a]` |
| `y` | 离散动作 token | `[B, T_act, D_a]` |
| `logits` | 分类 logits | `[B, T, D_a, N_bins]` |

**训练/推理频率不匹配**：视觉/触觉输入常见 10–30 Hz，控制环常见 125–500 Hz。工程做法是模型输出低频 chunk，控制端插值/滤波补成高频命令流。

## 4. Loss 地图

| 家族 | 代表方法 | 输出 | 多模态 | 典型场景 |
|---|---|---|---|---|
| 回归 | MSE / L1 / Huber | 点估计 | 否 | BC 基线、干净数据 |
| 概率回归 | Gaussian NLL | 均值 + 方差 | 否（单峰） | 不确定性、异常检测 |
| 序列 | Chunk BC + 时间加权 | 动作块 | 取决于头 | 高频控制、减少误差累积 |
| 离散 | Cross Entropy bins | 每维分类分布 | 是（每维） | RT-1/RT-2 风格、LLM 接口 |
| 混合密度 | GMM NLL | K 个高斯 | 是（K 个模式） | 多解任务、轻量替代 diffusion |
| 生成式 | Diffusion ε loss | 去噪网络 | 是 | 高精度、多模态轨迹 |
| 生成式 | Flow matching | 向量场 | 是 | 少步采样、高频部署 |
| 对齐 | InfoNCE / CLIP | 嵌入 | — | 图文/视触觉对齐、grounding |
| 正则 | Smooth / Barrier | 惩罚项 | — | 抖动、限位、安全 |
| 联合训练 | Loss masking | 梯度掩码 | — | web + robot 混训 |
| 蒸馏 | KL / MSE distill | 教师→学生 | — | 抗遗忘、加新模态 |
| RL | PPO / KL | 策略梯度 | 是（随机策略） | 少量微调、奖励优化 |

## 6. 工程上最常用的 6 套配方

1. **BC 基线**：MSE + action smooth。
2. **多解任务**：GMM NLL + smooth。
3. **高精度轨迹**：Diffusion ε loss + chunk + receding horizon。
4. **高频部署**：Flow matching + chunk + smooth。
5. **加入触觉不忘动作**：BC + replay + distill（KL/MSE）+ gating。
6. **RL 微调**：BC warm-start + PPO + KL-to-base + safety barrier。

> [!tip] 选型顺序
> 先用最简单的 BC 基线确认数据和 pipeline 没问题；如果多解明显，再上 GMM 或 Diffusion；如果推理频率不够，换 Flow 或 chunk；如果抖动/超力，加正则和 barrier；最后才考虑 RL 微调。不要一上来就上最复杂的损失。
