# 07 · 安全正则与联合训练

> [!abstract] 一句话
> 动作损失保证“学会”，正则和安全项保证“能用”：平滑减少抖动，barrier 限制危险动作；联合训练用 loss masking 处理异构数据，蒸馏/回放防止加新模态后遗忘旧动作。

## 1. 动作平滑正则

目标：减少抖动、超力、碰撞，提升可部署性。

### 1.1 速度 / 加速度 / jerk 正则

$$
\mathcal{L}_{\text{smooth}}
=\lambda_v\sum_t\|a_t-a_{t-1}\|^2
+\lambda_a\sum_t\|(a_t-a_{t-1})-(a_{t-1}-a_{t-2})\|^2
$$

- 第一项惩罚速度突变；
- 第二项惩罚加速度突变；
- 需要更平滑时可以加 jerk（三阶差分）。

**适用**：

- teleop 数据的高频抖动；
- VTLA 接触阶段（抖动直接导致滑移/卡死）；
- 动作 chunk 拼接处。

**注意**：

- 权重太大会让动作“迟钝”，跟踪误差变大；
- 平滑项不能替代好的数据/动作表示，只是补丁；
- 推理端的 temporal ensemble / 低通滤波通常比训练正则更直接。

### 1.2 最小实现

```python
vel = action[:, 1:] - action[:, :-1]
acc = vel[:, 1:] - vel[:, :-1]
loss_smooth = lambda_v * vel.pow(2).mean() + lambda_a * acc.pow(2).mean()
```

## 2. 约束 / 安全 barrier（软约束）

$$
\mathcal{L}_{\text{barrier}}=\sum_i \lambda_i \cdot \max(0, g_i(a,s))^2
$$

`g_i(a,s)` 是违反约束的量，例如：

- 关节限位：`q - q_max` 或 `q_min - q`；
- 速度限位：`|q_dot| - q_dot_max`；
- 力矩限位；
- TCP workspace 边界；
- 碰撞距离（用 signed distance）。

**特点**：

- 软约束，训练时惩罚，推理时仍建议加硬限幅/安全层；
- `max(0, ·)` 只惩罚违反项，不惩罚合法动作；
- 权重需要调，太大影响任务性能，太小约束无效。

## 3. 联合训练与 Loss Masking

不同数据源标签不同：

- web 数据：有文本，没有动作；
- 机器人数据：有动作，可能有文本；
- 触觉数据：有触觉/动作，语言可能弱。

**最小原则**：

| 数据 | 计算什么损失 | 梯度 |
|---|---|---|
| robot batch | action loss（+ 可选 text loss） | action head + 主干 |
| web batch | text loss only | action head 梯度为 0 |
| tactile batch | action loss + 视触觉对齐 | 对应模块 |

**实现方式**：

- 给每个样本一个 `has_action` / `has_text` mask；
- 对 action loss 乘 mask，再求平均；
- 或者把不同数据源拆成不同 forward，分别 backward；
- 注意 normalization：mask 后要按有效元素数平均，否则 batch 比例会改变损失尺度。

```python
action_loss = (per_element_loss * action_mask).sum() / action_mask.sum().clamp_min(1)
```

## 4. 蒸馏与遗忘抑制

典型场景：加入 tactile、新任务或 RL fine-tune 后，“旧动作能力掉了”。

### 4.1 离散动作：KL 蒸馏

$$
\mathcal{L}_{\text{KL}}=\operatorname{KL}(p_{\text{teacher}}\|p_{\text{student}})
$$

- 教师可以是旧模型、集成模型、更大模型；
- 温度 `T` 软化分布，学生学到的类别间关系更丰富。

### 4.2 连续动作：回归蒸馏

$$
\mathcal{L}_{\text{distill}}=\|a_{\text{student}}-a_{\text{teacher}}\|
$$

- 也可以蒸馏中间特征；
- 与任务损失加权：`L = L_task + λ L_distill`。

### 4.3 工程要点

- 蒸馏 loss 通常在“旧数据回放 batch”上启用（replay）；
- 配合 adapter/LoRA，减少对动作头的破坏；
- 旧数据不必全量，少量回放就能显著缓解遗忘；
- 监控旧任务成功率，别只看新任务。

## 5. 常见坑

| 问题 | 原因 | 缓解 |
|---|---|---|
| 动作变迟钝 | 平滑权重过大 | 降 λ，改推理端滤波 |
| 约束不生效 | barrier 权重太小/约束写错 | 检查 `g_i` 符号和量纲 |
| 联合训练梯度打架 | 不同数据源损失尺度不同 | loss masking + 归一化 |
| 新任务学崩旧任务 | 无 replay/蒸馏 | 回放 + KL/MSE distill + LoRA |
| 蒸馏不涨 | 教师学生容量差距过大 | 调温度、加中间层蒸馏、换教师 |
