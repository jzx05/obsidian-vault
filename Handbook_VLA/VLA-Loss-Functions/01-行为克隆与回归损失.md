# 01 · 行为克隆与回归损失

> [!abstract] 一句话
> BC 回归是最常见、最稳健的 VLA 基线：用 MSE/L1/Huber 让策略模仿专家动作。它实现简单、收敛快，但在多解任务上会把多个模式“平均”成一个可能无效的动作。

## 1. MSE（L2 回归）

**用途**：有大量示教轨迹，目标是“像专家一样做”。

**定义**：

$$
\mathcal{L}_{\text{MSE}}=\frac{1}{N}\sum_{i}\|a_i-\hat a_i\|_2^2
$$

**张量**：

- `pred_action`: `[B, T, D_a]`
- `gt_action`: `[B, T, D_a]`

**最小实现**：

```python
import torch.nn.functional as F

loss = F.mse_loss(pred_action, gt_action)
```

**优点**：

- 实现简单、收敛快；
- 可作为 GMM / Diffusion / Flow 的 warm-start；
- 对单峰、干净数据非常有效。

**缺点**：

- 多模态任务会取平均。典型例子：绕障有左右两条路，MSE 会预测中间，直接撞障碍；
- 对异常值敏感（平方放大跳点）；
- 不表达不确定性。

**挂载位置**：policy/action head 输出连续动作（Δpose、joint targets、velocities）。

**工程细节**：

- **动作维度加权**：位置、旋转、夹爪开合的尺度不同，直接 MSE 会让某一维支配梯度。可以给每维不同权重，或先做 per-dimension 归一化。
- **夹爪维度**：如果夹爪是二值/开合，单独用 BCE 或分类损失通常比 MSE 更稳。
- **padding mask**：变长轨迹要 mask 掉无效时间步，否则 padding 会污染损失。

## 2. L1 / Huber（抗异常）

**L1**：

$$
\mathcal{L}_{\text{L1}}=\frac{1}{N}\sum_i |a_i-\hat a_i|
$$

**Huber**（`δ` 为阈值）：

$$
\mathcal{L}_{\text{Huber}}=
\begin{cases}
\frac{1}{2}e^2,& |e|\le \delta\\
\delta(|e|-\frac{1}{2}\delta),& \text{otherwise}
\end{cases}
$$

**什么时候用**：

- teleop 数据偶尔跳点（丢帧、重投影错误）；
- 触觉信号偶发尖峰；
- 数据里有少量标注噪声。

**最小实现**：

```python
loss_l1 = torch.abs(pred_action - gt_action).mean()
loss_huber = F.smooth_l1_loss(pred_action, gt_action, beta=1.0)
```

**取舍**：

- L1 对异常值更鲁棒，但在 0 附近梯度不光滑，收敛可能慢；
- Huber 在小误差时像 MSE、大误差时像 L1，是常用的折中。

## 3. 高斯 NLL（heteroscedastic regression）

如果模型同时输出均值 `μ` 和方差 `σ²`（通常输出 `log σ²`），可以学习“这一步有多不确定”：

$$
\mathcal{L}_{\text{NLL}}=\frac{1}{2}\sum_i\left(\frac{(a_i-\mu_i)^2}{\sigma_i^2} + \log\sigma_i^2\right)
$$

**张量**：

- `mu`: `[B, T, D_a]`
- `log_var`: `[B, T, D_a]`

**最小实现**：

```python
import torch

var = torch.exp(log_var).clamp_min(1e-6)
loss = 0.5 * (((gt_action - mu) ** 2) / var + log_var).mean()
```

**优点**：

- 能表达“这一步我不确定”，利于安全、异常检测、主动学习；
- 方差可以作为置信度，指导数据采集或动作过滤。

**缺点**：

- 仍然是**单峰**分布，不解决多模态平均问题；
- 方差可能被滥用：模型把方差学得很大来降低损失，表现为“全都不确定”；
- 需要 clamp `log_var`，否则数值不稳定。

**工程建议**：

- 预测 `log_var` 而不是 `var`，数值更稳；
- 给 `log_var` 设上下界；
- 如果只关心点估计，MSE 通常足够，不必引入方差头。

## 4. 怎么选

| 情况 | 建议 |
|---|---|
| 单峰、干净、数据量大 | MSE |
| 有偶发跳点/尖峰 | L1 或 Huber |
| 需要不确定性/异常检测 | Gaussian NLL |
| 多解明显 | 不要用纯回归，转 [[04-GMM负对数似然]] 或 [[05-Diffusion与FlowMatching]] |
| 夹爪二值维度 | 单独 BCE/分类，不要混在 MSE 里 |

> [!warning] 最常见的误用
> 用 MSE 训一个多模态任务，然后归因于“模型容量不够”。实际上损失函数在优化一个错误的目标：它奖励“平均值”，而平均值可能根本不是一个合法动作。先看数据分布是不是多峰，再决定损失。
