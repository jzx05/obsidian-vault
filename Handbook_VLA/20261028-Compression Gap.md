# 压缩鸿沟：为何离散 Tokenization 限制 VLA 模型 Scaling

> [!abstract] 核心思想
> VLA 的 scaling 不取决于模型大小或数据量，而取决于**信息瓶颈所在的位置**。离散动作 tokenization（OAT）在视觉编码器与动作之间插入一个固定容量的量化关口，把瓶颈从编码器转移到码本；编码器升级带来的额外信息会在量化阶段被丢弃。连续动作表示（Diffusion Policy）没有这个关口，瓶颈留在编码器，因此能持续吸收上游视觉模型的进步。

> [!tip] Eureka Moment
> 升级视觉编码器在 VLA 中收益有限，不是因为编码器没用，而是因为离散动作接口把信息通道焊死了——换更粗的上游水管，流量仍被中间那个固定直径的阀门卡住。

**论文要回答的问题**：视觉编码器质量的提升，能否传递到机器人操作性能上？在什么条件下能传递？为了隔离动作表示方式的影响，论文比较两类方法——离散 token 化（OAT）与连续扩散（Diffusion Policy）。

## 🏗️ 两条信息通路

```text
连续路径（Diffusion Policy）

观察 → 视觉编码器 → 连续表征 → 去噪网络 → 连续动作
                    ↑
              瓶颈在这里；升级编码器直接放宽瓶颈


离散路径（OAT）

观察 → 视觉编码器 → 连续表征 → 量化器 → 离散 token → 自回归解码 → 动作
                              ↑
                    固定容量硬瓶颈；额外信息在这里被丢弃
```

关键差异只有一处：OAT 多了一个量化阶段。动作必须先被压缩成有限个离散 token，才能交给自回归模型生成。

### 两条路径对比

| 维度 | Diffusion Policy（连续） | OAT（离散） |
|---|---|---|
| 动作表示 | 连续向量 | 离散 token 序列 |
| 信息通路 | 观察 → 表征 → 动作，全程连续 | 观察 → 表征 → token → 动作，含量化 |
| 码本容量 | 无硬上限 | 约 80 bits（8 个 token × 1000 词表） |
| 编码器升级收益 | 高（+21～26 个百分点） | 低（+3～10 个百分点） |
| 增大模型收益 | 有效（+12～14 个百分点） | 无效或不稳定 |
| 与 LLM 接口 | 需额外适配 | 天然兼容（token 接口） |
| 低质量编码器下 | 较差 | 较好（结构化补偿） |

## 🔑 关键机制：瓶颈位置决定 scaling

### 1. 信息传不过最窄的一环

从观察到动作的信息流是一条链，链上每一环都可能损失信息；整条链能传过去的信息，不会超过最窄的那一环。连续路径的最窄环是视觉编码器；离散路径的最窄环是量化器。升级一个不是瓶颈的环节，收益会被瓶颈截断。

### 2. 连续路径：瓶颈在编码器

Diffusion Policy 全程保持连续：编码器输出连续表征，去噪网络直接生成连续动作，中间没有任何有限容量的离散接口。编码器越强，表征包含的任务相关信息越多，动作头能利用的也越多。因此视觉基础模型的每一次迭代都能向下游传导。

### 3. 离散路径：瓶颈在码本

OAT 先把连续动作块量化成 8 个离散 token，每个 token 从约 1000 个码字中选一个；整条动作序列最多携带约 80 bits 信息。这个上限由**词表大小和序列长度**决定，与视觉编码器多强无关。编码器给出的表征再丰富，量化时也只能保留落在码本里的那一部分，其余信息直接丢弃。

因此离散路径的 scaling 曲线会出现两个特征：

- 继续升级编码器，性能提升很小（瓶颈不在编码器）；
- 继续增大策略模型，性能不稳定甚至下降（瓶颈不在模型容量）。

### 4. 反直觉后果：弱编码器下 OAT 反而更强

在 ResNet-18 上，OAT 成功率 53.8%，Diffusion Policy 只有 36.4%——结构化 tokenization 补偿了有限的感知信息，把动作空间的组织先验注入了模型。但换成 SigLIP 后，Diffusion Policy 提升 21.2 个百分点，OAT 只提升 3.6 个百分点。所以结论不是"离散一定更差"，而是：**在弱感知下离散有补偿优势，在强感知下离散吃不到上游红利**。

## 🧩 相关方法：OAT（Ordered Action Tokenization）

> [!info] 论文信息
> **OAT: Ordered Action Tokenization**，Liu et al.，RSS 2026，arXiv:2602.04215。

### OAT 要解决什么

自回归 VLA 必须把连续动作变成 token。朴素逐维分箱序列太长；普通 VQ/FSQ token 之间没有顺序结构，自回归生成时难以从粗到细地组织动作。OAT 的目标是让离散 token 空间本身具有**因果有序**的结构：先生成的 token 决定动作的粗轮廓，后生成的 token 补充细节。

### 核心机制

- **有限标量量化（FSQ）**：把连续动作块压成少量离散 token，典型配置是 8 个 token、词表约 1000。
- **嵌套 dropout**：训练时按顺序丢弃靠后的 token，迫使靠前的 token 承载更粗粒度的信息、靠后的 token 只承载残差细节，从而形成因果有序的 token 空间。
- **自回归解码**：按顺序生成 token，天然适配 LLM 的 next-token 接口，并支持从粗到细的解码。
- **register token**（据 NAC 拆解归纳）：为序列提供稳定的生成起点或上下文。

### 为什么 OAT 天然有压缩上限

OAT 的表达能力被"序列长度 × 词表大小"锁死，默认配置约 80 bits。这是**设计特性**，不是实现缺陷：有序离散接口换来了与 LLM 的统一和粗到细生成，代价是固定容量的信息瓶颈。

论文也显示，增大词表可以部分恢复编码器敏感度：当词表从 1000 增到 1920 时，ResNet 下的性能差异重新暴露，说明瓶颈确实由码本容量控制。但增大词表的代价是训练和推理复杂度上升，不是免费午餐。

### OAT 在 tokenizer 谱系中的位置

```text
Bin（逐维分箱）
  → FAST（频域压缩）
  → VQ-VLA（单级矢量量化）
  → OAT（有序 token 空间）
  → NAC / FASTer / ActionPiece（后续工作）
```

OAT 的贡献不只是压缩率，而是让离散 token 具有因果顺序，便于自回归粗到细生成。它的局限——固定容量瓶颈——正是 Compression Gap 一文要揭示的东西。

## 📊 关键数据（LIBERO-10）

**实验设置**：10 个任务 × 每任务 50 条演示，Franka Emika Panda，7 维动作空间；因子实验 2×2×2（动作表示 × 编码器 × 模型大小）；4 个编码器（ResNet-18、SigLIP、DINOv2、SigLIP 2）；3 个词表大小（1000、1920、4375）；300 epochs，单卡 A100；每 50 epochs 做 500 次 rollout，报告峰值成功率。

| 动作表示 | 模型大小 | ResNet-18 | SigLIP | 编码器升级收益 |
|---|---|---|---|---|
| Diffusion Policy | M | 36.4% | 57.6% | +21.2 |
| Diffusion Policy | L | 44.0% | 70.0% | +26.0 |
| OAT | M | 53.8% | 57.4% | +3.6 |
| OAT | L | 48.0% | 58.4% | +10.4 |

**怎么读这张表**：

- **弱编码器（ResNet-18）**：OAT 明显更强（53.8 vs 36.4），结构化表示补偿了感知不足。
- **强编码器（SigLIP）**：M 规模两者几乎打平（57.6 vs 57.4），L 规模 Diffusion Policy 大幅领先（70.0 vs 58.4）。
- **编码器升级收益**：连续路径 +21～26 个百分点，离散路径只有 +3～10 个百分点——差距不在绝对性能，而在**能否继续吸收上游进步**。
- **模型升级收益**：Diffusion Policy 从 M 到 L 提升明显；OAT 在 ResNet 下甚至下降（53.8 → 48.0），scaling 不稳定。

## 🧭 工程判断：什么时候选哪条路

| 场景 | 建议 | 理由 |
|---|---|---|
| 视觉编码器会持续升级、追求长期 scaling | 连续表示（Diffusion / Flow） | 上游收益能传导到动作 |
| 边缘或嵌入式部署，编码器质量有限 | 离散（OAT）仍可用 | 结构化 tokenization 补偿感知不足 |
| 需要与预训练 LLM 统一 token 接口 | 离散 | 天然兼容 prefix decoding |
| 推理延迟敏感 | 需实测 | OAT 只需生成 8 个 token，可能快于多步去噪 |
| 码本容量可调 | 增大词表可部分恢复敏感度 | 但训练/推理复杂度上升 |

## 🧩 局限与失败模式

- **假设码本容量固定**：实际可以调大词表，但会改变训练和推理复杂度，论文只做了有限网格。
- **假设信息瓶颈是唯一限制**：优化难度、数据质量、任务分布同样影响 scaling，论文把其他因素控制住了，真实系统未必如此。
- **仅在 LIBERO-10 单臂 7 维动作上验证**：移动操作、双臂、人形全身控制需要重新验证。
- **峰值成功率是单一指标**：未覆盖方差、鲁棒性、OOD 泛化。
- **不可过度解读为"离散已死"**：低质量编码器下 OAT 仍可能更强；离散在 LLM 接口和推理速度上仍有结构优势。
- **tokenizer 训练目标可能与论文设定不同**：真实系统若以控制而非重建为目标，瓶颈的实际松紧会变化。

## 💡 一句话版本

离散动作 tokenization 在视觉表征和动作之间插了一道固定容量的量化关口，等于给信息通路焊死了天花板；连续表示没有这道关口，瓶颈留在视觉编码器，所以上游一升级，收益就能一路传到动作输出。
