# RDT-1B — 双臂扩散基础模型

> [!abstract] 核心思想
> RDT-1B 是面向双臂操作的 1.2B 扩散基础模型。它用**冻结的 SigLIP/T5 编码器**提供视觉-语言条件，把 proprio、noisy action chunk、控制频率编码成低维 token，送进 **28 层 DiT**，用 **x0-prediction 扩散**生成 64 步动作块；数据层用 **128 维物理可解释统一动作空间**把 46 个异构机器人数据集对齐，再在 6K+ 双臂数据上微调。

> [!tip] Eureka Moment
> RDT 的核心不是“把 DiT 堆到 1.2B”，而是“**让异构多机器人数据在同一个物理动作空间里可训练**”。统一动作空间解决数据对齐，扩散解决双臂多模态，DiT 解决规模，DPM-Solver++ 解决实时性。

## ⚡ 快速判断

| 维度 | 判断 |
|---|---|
| 核心结论 | 1.2B DiT + 扩散 + 128D 统一动作空间 + 46 数据集预训练 + 6K+ 双臂微调 |
| 适合精读 | 做双臂操作、扩散策略、跨机器人预训练、VLA 基础模型的人 |
| 可以跳过 | 只做高频连续控制（看 π0/flow）、只做单臂小数据（看 ACT/DP） |
| 落地可行性 | 中：1.2B 推理需 RTX 4090 级别；论文报告 6 Hz chunk / 31 Hz action |
| 主要风险 | 目标机器人仍需微调；不是新机器人零样本；离散/连续动作空间固定；扩散采样延迟 |

## 🏗️ 1. 架构与信息流

### 1.1 总图

```text
图像（3 相机 × 2 帧）
  → 冻结 SigLIP → patch token → 2 层 MLP adaptor → 2048-d image tokens ─┐
                                                                        │
语言指令                                                               │
  → 冻结 T5-XXL → text token → 2 层 MLP adaptor → 2048-d text tokens ──┤
                                                                        │
proprio z_t、noisy action a_{t:t+63}、控制频率 c                        │
  → MLP + Fourier features → 1 + 64 + 1 = 66 个低维 token ─────────────┤
                                                                        │
                                                                        ▼
                                             28 × DiT Block
                                             ├─ self-attention（66 个低维 token）
                                             ├─ cross-attention（图像/文本，ACI 交替）
                                             ├─ QKNorm + RMSNorm
                                             └─ MLP decoder
                                                                        │
                                                                        ▼
                                                     预测干净动作 â^0（64 × 128）
                                                                        │
                                                                        ▼
                                              DPM-Solver++ 5 步 → 动作 chunk
```

### 1.2 模块表

| 模块 | 输入 | 输出 | 关键设计 |
|---|---|---|---|
| 视觉编码 | 3 相机 × 2 帧 RGB | image tokens | 冻结 SigLIP；时空位置编码；2 层 MLP adaptor |
| 语言编码 | 指令文本 | text tokens | 冻结 T5-XXL；attention mask；2 层 MLP adaptor |
| 低维编码 | proprio、noisy action、控制频率 | 66 tokens | MLP + Fourier features；in-context token |
| DiT backbone | 66 tokens + image/text 条件 | 去噪预测 | 28 层、2048 hidden、32 heads、1.2B |
| Action head | DiT 输出 | 干净动作 chunk | 非线性 MLP decoder；128D 统一动作空间 |
| 采样器 | 噪声 + 条件 | 动作 chunk | DPM-Solver++ 5 步；无 CFG |

### 1.3 和 RT-2 / OpenVLA 的区别

| 维度 | RT-2 | OpenVLA | RDT-1B |
|---|---|---|---|
| 主干 | PaLI-X / PaLM-E | Llama 2 7B | DiT（从零训练） |
| 动作表示 | 文本 token | 专用线性 head + bins | 连续动作 chunk + 扩散 |
| 多模态 | VLM 词表 | VLM + action head | 冻结 SigLIP/T5 + DiT |
| 多模态动作 | 离散 CE | 离散 CE | 扩散，保留多峰 |
| 双臂 | 有限 | 有限 | 专门优化 |
| 规模 | 5B/55B | 7B | 1.2B |

## 🔑 2. 核心技术

### 2.1 扩散建模多模态动作

- 双臂同一观测下有多种合理动作，回归会平均，VAE 表达力不足，离散化损失精度；
- 扩散直接建模 `p(a_{t:t+T_a-1} | o_t, ℓ)`，保留多个模式；
- 论文消融：Wash Cup 三项上 RDT (regress) 12.5/50/12.5 vs RDT (ours) 50/62.5/100。

### 2.2 DiT backbone 的三处机器人专用改造

1. **QKNorm + RMSNorm**：机器人数值范围不稳定；LayerNorm 的 centering 破坏时序对称性；RMSNorm 不 center。
2. **MLP decoder**：线性 decoder 表达不了非线性动作；去掉后灵巧任务下降。
3. **Alternating Condition Injection (ACI)**：图像 token 远多于文本；相邻层交替注入图像/文本 cross-attention，避免图像压过语言。

> 注意：不是 AdaLN-Zero；论文明确说原版 adaptive layer norm 不适合高维/变长条件。

### 2.3 异构多模态输入编码

- 低维输入：proprio + noisy action + 控制频率 → MLP + Fourier features → 66 tokens；
- 图像：冻结 SigLIP → 2 层 MLP adaptor → 2048-d；
- 语言：冻结 T5-XXL → 2 层 MLP adaptor → 2048-d；
- 随机模态 masking 10%，防止过度依赖某一输入（外部相机 vs 腕部相机）。

### 2.4 128D 物理可解释统一动作空间

- 不是简单 pad 到 32D；论文是 **128 维**，每个 index range 有物理含义；
- 右臂/左臂关节位置、夹爪、速度、EEF 位置、6D 位姿、角速度、reserved；
- 不同机器人按物理含义填入，其余 padding + mask；
- 这是 46 个异构数据集能联合预训练的关键。

### 2.5 动作 chunk 与 receding horizon

- 一次预测 `T_a = 64` 步动作；
- 训练时对整段 chunk 算损失；
- 推理时执行前若干步，滚动重规划；
- 减少决策次数、误差累积，提升时序一致性。

## 🎛️ 3. 扩散训练与采样

### 3.1 前向加噪

```text
a^k = sqrt(ᾱ_k) · a^0 + sqrt(1 - ᾱ_k) · ε
ε ~ N(0, I), k = 1..K, K = 1000
```

### 3.2 x0-prediction 训练

网络 `fθ(ℓ, o_t, ã_t, k)` 直接预测干净动作 `â^0`：

```text
L(θ) = MSE(a^0, fθ(ℓ, o_t, sqrt(ᾱ_k) a^0 + sqrt(1-ᾱ_k) ε, k))
```

> 注意：RDT 是 **x0-prediction**，不是 `rdt.md` 写的 ε-prediction。

### 3.3 DDPM 反向

```text
a^{k-1} = (sqrt(ᾱ_{k-1}) β_k / (1-ᾱ_k)) · â^0
        + (sqrt(α_k)(1-ᾱ_{k-1}) / (1-ᾱ_k)) · a^k
        + σ_k z
```

### 3.4 DPM-Solver++ 5 步

- 训练：DDPM + glide cosine，1000 步；
- 推理：DPM-Solver++ + glide cosine，5 步；
- 论文报告：从 100 步降到 5 步；RTX 4090 24GB 上 6 Hz chunk / 31 Hz action；
- 不是 DDIM；`rdt.md` 的 DDIM 10 步是错的。

### 3.5 训练配置

| 项目 | 数值 |
|---|---|
| GPU | 48 × H100 80GB |
| 预训练 | 1M steps |
| 微调 | 130K steps，从 500K checkpoint 开始 |
| 优化器 | AdamW，constant LR |
| 模型 | 1.2B，28 层，2048 hidden，32 heads |
| 小模型 | 166M（消融用） |
| 动作 chunk | 64 |
| 图像历史 | 2 |

### 3.6 不用 CFG

论文明确说 CFG 没有提升性能，反而导致机械臂动作不稳定；因此 RDT 不做 classifier-free guidance。

## 📊 4. 数据与实验

### 4.1 预训练数据

- 46 个数据集、1M+ trajectories、21TB；
- 主数据集：RT-1 130K、DROID 76K、RH20T 110K、Mobile ALOHA 等；
- 采样权重 `sqrt(N_j)`，训练中按 loss 调整权重；
- 论文没有提 RoboTurk、500K 模拟数据、70/30 真机/仿真配比。

### 4.2 微调数据

- 6K+ 双臂 trajectories；
- 300+ tasks、100+ objects、15+ rooms；
- GPT-4 改写指令，增加语言多样性；
- 目标机器人：Cobot Mobile ALOHA（双臂 + 3 相机）。

### 4.3 结果

- 7 个真机任务：Wash Cup、Pour Water、Pour Water-L-1/3、Pour Water-R-2/3、Handover、Fold Shorts、Robot Dog；
- 论文报告相对 baseline **56% relative improvement**；
- zero-shot：未见物体/场景/指令；
- few-shot：1–5 条新技能演示；
- 精细操作：Robot Dog 摇杆控制。

### 4.4 消融（Table 2）

| 变体 | Unseen Object | Unseen Scene | Instruction Following |
|---|---|---|---|
| RDT (regress) | 12.5 | 50 | 12.5 |
| RDT (small, 166M) | 37.5 | 62.5 | 25 |
| RDT (scratch) | 0 | 25 | 62.5 |
| RDT (ours) | 50 | 62.5 | 100 |

结论：扩散、模型规模、预训练三者都必要。

## 🧩 5. 能力与失败模式

### 5.1 能做

- 双臂精细操作、长序列任务；
- 未见物体/场景/指令的零样本泛化；
- 1–5 条演示的新技能 few-shot；
- 跨机器人预训练 + 目标机器人微调；
- 6 Hz chunk / 31 Hz action 的实时推理。

### 5.2 不能做 / 失败模式

- **不是新机器人零样本**：目标机器人仍需 6K+ 微调；
- 动作空间固定 128D，对灵巧手/人形扩展有限；
- 扩散采样仍有延迟，极高频控制需要蒸馏/少步；
- 双臂数据稀缺，微调数据成本高；
- 没有显式 Cross-Arm Attention 模块；双臂协调靠统一空间 + 联合扩散；
- 视觉单帧/多相机配置固定；遮挡、动态场景鲁棒性有限。

### 5.3 隐含假设

- 假设 128D 统一空间能覆盖目标机器人；
- 假设 64 步 chunk 足够；
- 假设冻结 SigLIP/T5 的语义足够；
- 假设目标域与预训练分布差异可通过 6K+ 微调弥合；
- 假设扩散的多模态建模优于回归/VAE/离散化。

| 方法 | 架构 | 动作表示 | 规模 | 双臂 | 预训练 |
|---|---|---|---|---|---|
| ACT | CVAE + Transformer | 连续 chunk | ~10M | ✅ | 否 |
| Diffusion Policy | U-Net | 连续 chunk | ~50M | 有限 | 否 |
| OpenVLA | Llama 2 + action head | 离散 bins | 7B | 有限 | ✅ |
| Octo | Transformer + diffusion | 连续/离散 | 93M | 有限 | ✅ |
| π0 | VLM + flow matching | 连续 | 3B+ | ✅ | ✅ |
| **RDT-1B** | **DiT + diffusion** | **连续 chunk** | **1.2B** | **专门优化** | **✅** |

### U-Net vs DiT（RDT 为什么选 DiT）

| 维度 | U-Net | DiT |
|---|---|---|
| 结构 | 卷积编码器-解码器 + skip | token + Transformer |
| 感受野 | 局部、多尺度 | 全局 |
| 数据需求 | 较低 | 较高 |
| 扩展性 | 中等 | 强，易到 1B+ |
| 多模态/变长 | 需额外融合 | 天然 token 接口 |
| 代表 | Diffusion Policy | RDT-1B、DiT、SD3 |

## 🎤 7. 面试问答

**Q1：RDT-1B 的核心贡献是什么？**

A：不是单纯把 DiT 堆到 1.2B，而是用 128D 物理可解释统一动作空间把 46 个异构机器人数据集对齐，用扩散 Transformer 预训练，再在 6K+ 双臂数据上微调；扩散解决双臂多模态，DiT 解决规模，DPM-Solver++ 解决实时性。

**Q2：为什么用扩散而不是回归/VAE/离散化？**

A：双臂动作多模态，回归会平均，VAE 表达力不足，离散化损失精度；扩散建模完整条件分布。消融上 RDT (regress) 在 Wash Cup 三项只有 12.5/50/12.5，RDT (ours) 是 50/62.5/100。

**Q3：RDT 的 DiT 和原版 DiT 有什么不同？**

A：三处改造：QKNorm + RMSNorm 稳定数值/保时序对称性；MLP decoder 提升非线性动作表达；ACI 交替注入图像/文本，避免图像 token 压过语言。不是 AdaLN-Zero。

**Q4：128D 统一动作空间为什么重要？**

A：不同机器人动作维度和语义不同；按物理含义填到固定位置，padding + mask，模型才能跨机器人学习共享运动知识。简单 pad 到 32D 会让同一维在不同机器人上代表不同物理量。

**Q5：RDT 怎么做实时推理？**

A：训练用 DDPM 1000 步，推理用 DPM-Solver++ 5 步；RTX 4090 24GB 上 6 Hz chunk / 31 Hz action；不用 CFG，因为 CFG 会让机械臂动作不稳定。

**Q6：RDT 和 π0 / OpenVLA 的区别？**

A：OpenVLA 是 LLM + 离散 action head，单步；π0 是 VLM + flow matching，连续高频；RDT 是 DiT + diffusion + 双臂统一动作空间，1.2B，专门优化双臂和跨机器人预训练。
