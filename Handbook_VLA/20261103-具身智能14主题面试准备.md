## 1–2 线性代数

### 🧪 动手题

#### 题 1：手推 LoRA 的参数节省量

设预训练权重 `W0 ∈ R^{d×k}`。LoRA 不直接更新 `W0`，而是学习一个低秩增量：

```text
W = W0 + (α/r) · B A
B ∈ R^{d×r},  A ∈ R^{r×k},  r << min(d, k)
```

要求：

- [ ] 写出全量微调和 LoRA 的参数量。
- [ ] 计算 `d = k = 4096, r = 8` 时的参数量、占比和节省比例。
- [ ] 解释 `α/r` 的作用。
- [ ] 解释为什么 `B` 初始化为 0、`A` 随机初始化。
- [ ] 写出推理时如何合并权重、为什么合并后没有额外延迟。

**参考要点**：

- 全量参数：`d × k`。
- LoRA 参数：`r × k + d × r = r(d + k)`。
- 节省比例：`1 - r(d + k) / (d k)`。
- `d = k = 4096, r = 8`：全量 `16,777,216`；LoRA `65,536`；约 `0.39%`；节省约 `99.61%`。
- `α/r` 是缩放因子：改变 `r` 时保持增量幅度稳定，相当于给 LoRA 分支一个独立的有效学习率。
- `B = 0` 时 `BA = 0`，训练开始时模型等价于原模型；第一步 `A` 先获得梯度，之后 `B` 开始学习。如果 `A`、`B` 都初始化为 0，则梯度全为 0，无法学习。
- 推理合并：`W_merged = W0 + (α/r) BA`，之后走普通线性层。

#### 题 2：用 NumPy 实现 SVD 压缩一张图

要求：

- [ ] 读取一张灰度图，转成矩阵。
- [ ] 做 SVD，保留前 `k` 个奇异值，重构图像。
- [ ] 计算压缩率、MSE、PSNR。
- [ ] 画 `k = 5, 20, 50, 100` 的重构对比。
- [ ] 解释为什么 SVD 能压缩、为什么 `k` 越大越清晰。

**参考代码**：

```python
import numpy as np
from PIL import Image

img = np.array(Image.open("image.png").convert("L"), dtype=np.float64)
U, s, Vt = np.linalg.svd(img, full_matrices=False)

k = 50
img_k = (U[:, :k] * s[:k]) @ Vt[:k, :]

mse = np.mean((img - img_k) ** 2)
psnr = 10 * np.log10(255 ** 2 / mse)

# 存储量：原图 m*n；压缩后 k*(m+n+1)
ratio = k * (img.shape[0] + img.shape[1] + 1) / (img.shape[0] * img.shape[1])
```

**要点**：

- SVD 把矩阵分解成“正交基 × 奇异值 × 正交基”。
- 奇异值按重要性排序；自然图像的能量集中在前几个奇异值上。
- Eckart–Young 定理：截断 SVD 是 Frobenius 范数下最优的低秩近似。
- 压缩率不是只看 `k`，还要算上 `U`、`V` 的存储；`k` 很小时才真正省空间。

### 🧠 深度问题

1. **LoRA 为什么有效？** 低内在秩假设：下游任务的权重更新集中在一个低维子空间；LoRA 用低秩矩阵参数化这个子空间。
2. **LoRA 的秩 `r` 怎么选？** 任务越复杂、数据越多、域偏移越大，`r` 通常越大；但 `r` 太大会失去参数效率，也更容易过拟合。实践中从 `r = 8/16/32` 做 sweep。
3. **LoRA 和 full fine-tuning 的本质差别？** 参数效率、显存、可合并、多适配器切换；full FT 自由度更高，适合大域偏移或新模态。
4. **SVD 的奇异值代表什么？** 每个奇异值表示对应方向上的“能量”或重要性；奇异值衰减越快，矩阵越低秩。
5. **SVD 和 PCA 的关系？** PCA 对中心化数据的协方差矩阵做特征分解；SVD 直接分解数据矩阵，数值更稳定， rectangular 矩阵也能用。
6. **LoRA 的局限？** 低秩瓶颈可能欠拟合复杂任务；多 LoRA 合并会冲突；与量化、蒸馏、多模态扩展的交互需要额外设计。
7. **为什么 LoRA 可以合并？** 因为增量是线性的 `BA`，推理时直接加到原权重上；但多个 LoRA 同时使用时，合并顺序和缩放需要小心。

### 🎤 面试题与答案

**Q1：推导 LoRA 的参数节省量。**

A：全量微调更新 `d×k` 个参数；LoRA 用 `B ∈ R^{d×r}` 和 `A ∈ R^{r×k}`，参数量是 `r(d+k)`。以 `d=k=4096, r=8` 为例，全量约 1678 万，LoRA 约 6.5 万，只有 0.39%，节省 99.6%。代价是增量被限制在秩 `r` 的子空间里。

**Q2：为什么 LoRA 的 `B` 初始化为 0，`A` 随机初始化？**

A：为了保证训练开始时 `BA = 0`，模型输出和预训练模型完全一致，不会一上来就破坏已学到的表示。第一步 `B = 0` 时，`A` 仍然能拿到梯度；如果 `A` 和 `B` 都初始化为 0，则梯度为 0，整个分支学不动。

**Q3：`α/r` 的作用是什么？**

A：它是 LoRA 增量的缩放系数。改变 `r` 时，`α/r` 能让增量的有效幅度保持稳定，避免“换个秩就要重调学习率”。很多实现默认 `α = r` 或 `α = 2r`。

**Q4：SVD 为什么能压缩图像？**

A：自然图像通常近似低秩：大部分能量集中在前若干个奇异值对应的方向上。截断 SVD 丢掉尾部小奇异值，只保留主要结构，从而用 `k(m+n+1)` 个数代替 `mn` 个数。Eckart–Young 保证这是 Frobenius 范数下最优的秩 `k` 近似。

**Q5：LoRA 和 Adapter、Prefix Tuning 的区别？**

A：LoRA 在权重上加低秩增量，可合并、推理无额外延迟；Adapter 在层间插入小模块，增加串行深度，通常不能完全合并；Prefix Tuning 在输入/每层前加可学习 token，改变的是上下文而不是权重。三者都是参数高效微调，但 LoRA 的“可合并”是工程上的关键优势。

**Q6：什么时候不用 LoRA，直接全量微调？**

A：域偏移很大（新模态、新语言、新任务分布）、数据充足、算力足够，或者需要模型学到高秩的结构性变化时。LoRA 更适合“在已有能力上做轻量适配”。

## 3–4 3D 几何

### 🧪 动手题

#### 题 1：实现 SE(3) 坐标变换

要求：

- [ ] 用 4×4 齐次矩阵表示 `T = [[R, t], [0, 1]]`。
- [ ] 实现 `compose(T1, T2)`、`inverse(T)`、`transform_point(T, p)`。
- [ ] 验证 `T @ T^{-1} = I`，以及组合顺序对结果的影响。
- [ ] 用 NumPy 写，不调用现成的 3D 库。

**参考**：

```python
import numpy as np

def compose(T1, T2):
    return T1 @ T2

def inverse(T):
    R, t = T[:3, :3], T[:3, 3]
    T_inv = np.eye(4)
    T_inv[:3, :3] = R.T
    T_inv[:3, 3] = -R.T @ t
    return T_inv

def transform_point(T, p):
    return T[:3, :3] @ p + T[:3, 3]
```

#### 题 2：6D → 旋转矩阵

要求：

- [ ] 输入两个 3D 向量 `a1, a2`，用 Gram–Schmidt 构造旋转矩阵。
- [ ] 处理退化情况：`a1` 和 `a2` 平行时怎么办。
- [ ] 验证输出 `R` 满足 `R^T R = I`、`det(R) = 1`。
- [ ] 解释为什么 6D 表示比欧拉角、四元数更适合网络回归。

**参考**：

```python
def sixd_to_rot(a1, a2):
    b1 = a1 / np.linalg.norm(a1)
    a2_orth = a2 - np.dot(b1, a2) * b1
    b2 = a2_orth / (np.linalg.norm(a2_orth) + 1e-8)
    b3 = np.cross(b1, b2)
    return np.stack([b1, b2, b3], axis=1)  # 列向量
```

#### 题 3（可选）：四元数与 SLERP

- [ ] 实现四元数归一化、四元数转旋转矩阵。
- [ ] 实现 SLERP，比较它和“旋转矩阵线性插值再正交化”的差异。

### 🧠 深度问题

1. **为什么用 6D 旋转表示？** 欧拉角有万向锁，四元数有双覆盖和符号跳变；6D 连续、无奇点、网络容易回归。代价是过参数化，不唯一。
2. **6D 表示是连续的吗？** 是。Gram–Schmidt 对输入连续；但输入到旋转的映射不是一一对应，不同的 6D 输入可能得到同一个旋转。
3. **SE(3) 和 SO(3) 的关系？** SO(3) 是旋转群；SE(3) 是刚体变换群，包含旋转和平移。SE(3) 不是旋转和平移的直积，因为平移会被旋转作用。
4. **李群和李代数在优化里怎么用？** 旋转矩阵在流形上，不能直接做无约束加减；在切空间（李代数）里做增量，再通过指数映射回到群上。常见做法是左扰动或右扰动。
5. **四元数的双覆盖是什么？** `q` 和 `-q` 表示同一个旋转；网络回归时要注意符号一致性，否则损失会跳变。
6. **主动变换和被动变换的区别？** 主动是“点/物体动”，被动是“坐标系动”；两者互为逆。代码里最容易错的是左乘还是右乘。
7. **旋转怎么算损失？** 可以用测地线距离、四元数点积、6D 的 MSE、或旋转矩阵的 Frobenius 距离；直接对欧拉角算 MSE 往往不合理。
8. **手眼标定在解决什么？** 求相机坐标系和机器人末端/基座之间的刚体变换；核心是 `AX = XB` 形式的方程。

### 🎤 面试题与答案

**Q1：写出 SE(3) 的乘法、逆和点变换。**

A：`T = [[R, t], [0, 1]]`；`T1 T2` 表示先做 `T2` 再做 `T1`；逆是 `[[R^T, -R^T t], [0, 1]]`；点变换是 `p' = R p + t`。齐次坐标下就是矩阵乘法。

**Q2：为什么 6D 旋转表示适合深度学习？**

A：它把旋转表示成两个无约束的 3D 向量，网络可以自由回归；Gram–Schmidt 保证输出是合法旋转。欧拉角有万向锁和周期性，四元数有符号歧义，都会让回归目标不连续。6D 的连续性让梯度更稳定。

**Q3：四元数和旋转矩阵的区别？为什么四元数要归一化？**

A：旋转矩阵 9 个数、带正交约束；四元数 4 个数、带单位范数约束。四元数更紧凑、插值方便，但 `q` 和 `-q` 表示同一旋转。数值积分或网络输出后会漂移，归一化是为了保持单位范数，避免缩放和扭曲。

**Q4：什么是 SO(3) 的指数映射？**

A：把李代数 `so(3)` 中的轴角向量映射到旋转矩阵，罗德里格斯公式给出闭式解。它用于把优化中的小增量 `δθ` 转成旋转更新；反方向是对数映射。

**Q5：如何把相机坐标系下的点云变换到世界坐标系？**

A：`p_world = R_cw p_cam + t_cw`，齐次形式是 `T_cw @ [p, 1]`。注意 `T_cw` 和 `T_wc` 互为逆，方向搞反是常见 bug。

**Q6：如何插值两个旋转？**

A：四元数用 SLERP；旋转矩阵可以用测地线插值或先转四元数再 SLERP。不要直接对旋转矩阵做线性插值，结果一般不是正交矩阵，需要重新正交化。

**Q7：网络回归旋转时，你会怎么设计损失和输出？**

A：输出 6D，Gram–Schmidt 转成旋转矩阵；损失可以用测地线距离、四元数点积或 6D 的 MSE。训练时注意符号一致性和退化情况；评估时用角度误差（度）而不是原始参数误差。

## 5–6 概率论

### 🧪 动手题

#### 题 1：推导 MSE = 高斯 NLL

设 `y = f(x) + ε`，`ε ~ N(0, σ²I)`。要求：

- [ ] 写出 `p(y | x)`。
- [ ] 写出负对数似然，并去掉与 `f` 无关的常数。
- [ ] 证明最小化 NLL 等价于最小化 MSE。
- [ ] 讨论 `σ` 固定和 `σ` 可学习两种情况的区别。
- [ ] 推广到每个样本有自己的方差（heteroscedastic）。

**参考**：

```text
p(y|x) = (2πσ²)^(-d/2) exp( -||y - f(x)||² / (2σ²) )

NLL = ||y - f(x)||² / (2σ²) + (d/2) log(2πσ²)
```

`σ` 固定时，第二项是常数，最小化 NLL 就是最小化 MSE。`σ` 可学习时，模型还要预测方差；`log σ` 项防止方差无限变大，但方差过大也会被惩罚。

#### 题 2：实现带重参数化的 VAE

要求：

- [ ] Encoder 输出 `μ` 和 `log σ²`。
- [ ] 用 `z = μ + σ ⊙ ε, ε ~ N(0, I)` 采样。
- [ ] Decoder 重建输入。
- [ ] 损失 = 重建损失 + KL。
- [ ] 在 MNIST 上训练，可视化 latent space 和重建结果。

**参考**：

```python
def reparameterize(mu, logvar):
    std = torch.exp(0.5 * logvar)
    eps = torch.randn_like(std)
    return mu + std * eps

def vae_loss(recon_x, x, mu, logvar):
    recon = F.binary_cross_entropy(recon_x, x, reduction="sum")
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon + kl
```

#### 题 3（可选）：从 ELBO 推导 VAE 损失

- [ ] 从 `log p(x)` 出发，引入 `q(z|x)`，用 Jensen 不等式得到 ELBO。
- [ ] 写出 ELBO 的两项：重建项和 KL 项。
- [ ] 解释为什么最大化 ELBO 等价于最小化 `-ELBO`。

### 🧠 深度问题

1. **为什么需要重参数化？** 采样本身不可导；把随机性移到 `ε`，`z` 对 `μ`、`σ` 可导，才能用路径wise 梯度。相比 REINFORCE，方差更低。
2. **ELBO 的推导？** `log p(x) = log ∫ p(x,z) dz`，引入 `q(z|x)`，用 Jensen 得到 `log p(x) ≥ E_q[log p(x|z)] - KL(q(z|x) || p(z))`。
3. **KL 项的作用？** 把后验拉向先验 `N(0,I)`，让 latent space 规整、可采样；但 KL 太强会导致 posterior collapse。
4. **Posterior collapse 是什么？** 解码器忽略 `z`，`q(z|x)` 退化成先验，KL 趋于 0；生成时 `z` 不起作用。缓解：β-VAE、free bits、skip connection、减弱 decoder、KL annealing。
5. **MSE 和 cross-entropy 怎么选？** 连续值、高斯假设用 MSE；二值/概率输出用 BCE；多分类用交叉熵。关键是似然假设，不是指标名字。
6. **VAE、GAN、Diffusion 的区别？** VAE 优化 ELBO，训练稳定但样本偏模糊；GAN 对抗训练，样本锐利但难训、mode collapse；Diffusion 学去噪/score，样本质量高但采样慢。
7. **Amortized inference 是什么？** 用 encoder 一次前向输出 `q(z|x)` 的参数，而不是对每个样本单独优化变分参数；代价是 encoder 有近似误差。
8. **为什么 VAE 的先验通常选 N(0,I)？** 简单、可采样、KL 有闭式解；也让 latent 各维解耦。更复杂的先验可以用 flow、vamprior 等。

### 🎤 面试题与答案

**Q1：证明 MSE 是高斯 NLL 的等价形式。**

A：假设 `y = f(x) + ε`，`ε ~ N(0, σ²I)`，则 `p(y|x) = N(f(x), σ²I)`。取负对数：`||y - f||²/(2σ²) + (d/2)log(2πσ²)`。`σ` 固定时第二项与 `f` 无关，最小化 NLL 等价于最小化 MSE。若 `σ` 可学习，还要优化 `log σ`，这就是 heteroscedastic 回归。

**Q2：推导 VAE 的损失。**

A：`log p(x) ≥ E_q[log p(x|z)] - KL(q(z|x)||p(z))`。第一项是重建项，第二项是正则项。对对角高斯 `q` 和标准正态先验，KL 有闭式解：`-0.5 Σ(1 + log σ² - μ² - σ²)`。训练时最小化 `-ELBO`。

**Q3：为什么重参数化 trick 有效？**

A：原来 `z ~ q(z|x)` 的采样是随机节点，梯度不能直接穿过。改写为 `z = μ + σ ⊙ ε`，随机性只在 `ε`，`z` 对 `μ`、`σ` 可导。这样可以用低方差的路径wise 梯度，而不是高方差的 score-function 估计。

**Q4：什么是 posterior collapse？怎么缓解？**

A：解码器太强或 KL 项太强时，模型发现忽略 `z` 也能重建，`q(z|x)` 退化成先验，KL 趋近 0。缓解方法包括 β-VAE（调小 KL 权重）、free bits（只惩罚超过阈值的 KL）、KL annealing、skip connection、减弱 decoder、使用更丰富的先验。

**Q5：VAE 和 GAN 的优缺点？**

A：VAE 有明确的似然下界，训练稳定，latent 结构好，但样本容易模糊；GAN 样本锐利，但训练不稳定、容易 mode collapse、没有似然。实际选择看任务：需要稳定训练和 latent 表示选 VAE，需要高质量生成选 GAN/扩散。

**Q6：如果 `σ` 也可学习，会发生什么？**

A：模型可以预测每个样本的噪声水平。NLL 里的 `log σ` 项防止模型把方差无限放大；但如果优化不当，模型可能把难样本的方差调大来降低损失，导致“逃避”难样本。需要合理的参数化、下限或课程学习。

**参考**：

```python
import torch
import torch.nn.functional as F

def attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    weights = F.softmax(scores, dim=-1)
    return weights @ V, weights
```

**Multi-head 要点**：

```text
每个头：d_k = d_model / h
head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
输出 = Concat(head_1, ..., head_h) W^O
```

#### 题 3（可选）：实现一个 Transformer Block

- [ ] Pre-LN：`x = x + Attention(LN(x))`，`x = x + FFN(LN(x))`。
- [ ] Post-LN：`x = LN(x + Attention(x))`，`x = LN(x + FFN(x))`。
- [ ] 加残差、dropout、FFN（两层线性 + GELU）。

### 🧠 深度问题

1. **为什么除以 `√d_k`？** `Q·K` 的方差随维度线性增长；不缩放会让 softmax 进入饱和区，梯度变小。除以 `√d_k` 把方差拉回 1 附近。
2. **为什么需要多头？** 每个头在不同的子空间里学习不同的关系；多头可以同时关注局部、全局、语法、语义等模式。头不是越多越好，存在冗余。
3. **位置编码有哪些？** 正弦/余弦、可学习绝对位置、RoPE（旋转位置编码）、ALiBi（线性偏置）。RoPE 通过旋转把相对位置编码进 Q·K，外推性较好。
4. **Pre-LN 和 Post-LN 的区别？** Pre-LN 在子层前做归一化，残差路径更干净，训练更稳定，深层模型常用；Post-LN 在残差后归一化，原始 Transformer 用法，需要 warmup。
5. **Attention 的复杂度？** `O(n² d)`，长序列的瓶颈在 `n²`。FlashAttention 用分块和在线 softmax 减少显存访问，不改变精确结果；线性注意力、稀疏注意力、状态空间模型是替代路线。
6. **KV cache 是什么？** 自回归推理时缓存历史 token 的 K、V，避免每步重算；显存随序列长度增长，是长上下文推理的主要成本之一。
7. **因果掩码的作用？** 遮住未来位置，保证第 `t` 个 token 只能看到 `1..t`，防止训练时信息泄漏；训练可以并行，推理必须逐 token。
8. **Attention 为什么有效？** 可以看作一种内容寻址的软检索/联想记忆：query 和 key 的相似度决定从 value 里取什么。它没有卷积的局部性先验，因此更依赖数据和位置编码。

### 🎤 面试题与答案

**Q1：写出 scaled dot-product attention 的公式，并解释每一项。**

A：`Attention(Q,K,V) = softmax(QK^T / √d_k) V`。`Q` 是查询，`K` 是键，`V` 是值；`QK^T` 计算每个 query 和每个 key 的相似度；除以 `√d_k` 稳定方差；softmax 归一化成权重；最后对 `V` 加权求和。

**Q2：为什么除以 `√d_k`？**

A：假设 `Q`、`K` 的分量独立、均值 0、方差 1，点积的方差约为 `d_k`。维度越大，点积绝对值越大，softmax 越容易饱和，梯度越小。除以 `√d_k` 让方差回到 1 左右，训练更稳定。

**Q3：多头注意力的计算过程？**

A：把 `d_model` 拆成 `h` 个头，每个头有自己的 `W_Q`、`W_K`、`W_V`，维度是 `d_model/h`；每个头独立做 attention；把 `h` 个输出拼接，再乘 `W_O` 投影回 `d_model`。多头让模型在不同子空间里学习不同关系。

**Q4：Pre-LN 和 Post-LN 怎么选？**

A：Pre-LN 训练更稳定，深层模型通常不需要 warmup；Post-LN 是原始结构，表达能力强一些，但需要 warmup 和调参。现代大模型多用 Pre-LN 或其变体（RMSNorm）。

**Q5：KV cache 是什么？为什么能加速？**

A：自回归生成时，第 `t` 步的 K、V 只依赖前面的 token；缓存起来，下一步只需计算新 token 的 K、V，避免重复计算整个前缀。代价是显存随上下文长度线性增长。

**Q6：FlashAttention 为什么快？**

A：它不改变 attention 的数学结果，而是通过分块计算和在线 softmax，避免把 `n×n` 的注意力矩阵完整写入显存；减少 GPU 的显存读写，提升 IO 效率。长序列、显存受限时收益明显。

**Q7：RoPE 的原理？**

A：把 query 和 key 的维度成对旋转，旋转角度与位置成正比；这样 `Q·K` 只依赖相对位置。它不需要额外的位置 embedding，外推性比绝对位置编码好，常用于 LLM。

**Q8：Attention 的复杂度是多少？有哪些加速路线？**

A：标准 attention 是 `O(n² d)`，瓶颈是序列长度的平方。加速路线包括 FlashAttention（IO 优化）、稀疏/局部注意力、线性注意力、状态空间模型（Mamba）、KV cache 压缩、分块/流式推理。

### 🧠 深度问题

1. **Diffusion 的前向和反向过程分别是什么？** 前向是逐步加高斯噪声，把数据变成近似标准正态；反向是学习去噪，从噪声恢复数据。
2. **Diffusion 的损失怎么来的？** 从 ELBO 出发，可以化简成“预测噪声”的 MSE；也可以从 denoising score matching 推导。
3. **DDPM 和 DDIM 的区别？** DDPM 是随机采样，步数多；DDIM 是确定性采样，可以用更少步数，训练目标相同，采样过程对应一个 ODE。
4. **Flow Matching 和 Diffusion 的关系？** 两者都在学一个从噪声到数据的传输；diffusion 学 score/噪声，flow matching 直接回归速度场。Flow matching 可以用更直的条件路径，采样步数更少。
5. **为什么 flow matching 可以更少步？** 如果路径接近直线，ODE 求解更容易；rectified flow 通过 reflow 进一步拉直路径。
6. **Classifier-free guidance 是什么？** 同时训练条件和无条件模型，采样时把两者的 score/velocity 组合：`v = v_uncond + s(v_cond - v_uncond)`，`s` 越大越贴近条件，但多样性下降。
7. **Diffusion 为什么慢？** 采样需要多步迭代，每步一次网络前向；加速方法包括 DDIM、DPM-Solver、蒸馏、一致性模型、flow matching。
8. **Diffusion Policy 怎么用？** 以观测为条件，去噪生成一段动作块；可以建模多模态动作分布；推理时取一段执行，滚动进行。

### 🎤 面试题与答案

**Q1：推导 Diffusion 的训练损失。**

A：前向 `q(x_t|x_0) = N(√ᾱ_t x_0, (1-ᾱ_t)I)`，可以写成 `x_t = √ᾱ_t x_0 + √(1-ᾱ_t) ε`。从 ELBO 化简后，训练一个网络 `ε_θ(x_t, t)` 预测 `ε`，损失是 `||ε - ε_θ(x_t, t)||²`。直观上就是“给定加噪样本和时间步，猜出加进去的噪声”。

**Q2：DDPM 和 DDIM 的区别？**

A：DDPM 的反向过程是随机的，每步注入噪声，需要较多步数；DDIM 把反向过程改成确定性的，可以用更少步数采样，训练目标不变。DDIM 可以看作 diffusion 对应的概率流 ODE 的离散化。

**Q3：Flow Matching 和 Diffusion 的区别？**

A：Diffusion 学的是 score 或噪声，采样是随机/确定性的反向过程；Flow Matching 直接回归一个速度场，采样是解 ODE。Flow Matching 的训练是 simulation-free 的，条件路径可以选直线，因此常常能用更少步数。两者都属于连续时间生成模型。

**Q4：Classifier-free guidance 的原理？**

A：训练时随机丢弃条件，让同一个网络同时学会条件和无条件生成；采样时把两者的预测组合：`pred = pred_uncond + s(pred_cond - pred_uncond)`。`s > 1` 增强条件一致性，但会降低多样性，甚至产生过饱和样本。

**Q5：Diffusion 为什么采样慢？有哪些加速方法？**

A：因为要从纯噪声开始，迭代多步去噪，每步一次网络前向。加速方法：DDIM（更少步）、DPM-Solver（高阶 ODE 求解）、蒸馏（把多步教师压到少步学生）、一致性模型（直接预测终点）、flow matching（更直路径）。

**Q6：Diffusion Policy 的输入输出是什么？**

A：输入是观测（图像、状态）和噪声动作序列，输出是去噪后的动作块。训练时对真实动作加噪，学习预测噪声；推理时从噪声开始，条件于观测，迭代去噪出动作块，然后执行其中一段，滚动预测。动作块和扩散都能建模多模态。

**Q7：如何评估生成模型？**

A：没有单一指标。图像常用 FID、IS、precision/recall；似然模型看 NLL/ELBO；任务相关看下游成功率、多样性、模式覆盖。FID 对样本量和预处理敏感，不能只看一个数。

**Q8：什么是 score matching？**

A：学习数据分布的对数密度梯度（score），而不是密度本身。去噪 score matching 把“加噪数据的 score”作为回归目标，避免直接计算归一化常数；diffusion 的噪声预测和 score 有对应关系。

### 🧠 深度问题

1. **策略梯度定理是什么？** `∇J = E[∇ log π_θ(a|s) A(s,a)]`；用似然比技巧把“reward 对参数的梯度”转成“log 概率的梯度乘以 advantage”。
2. **REINFORCE 的方差为什么大？** 用整条轨迹的 return 作为 advantage 估计，方差随轨迹长度和奖励噪声增长；baseline 不改变期望，但能显著降低方差。
3. **Actor-Critic 和 REINFORCE 的区别？** Actor-Critic 用学到的 value 函数估计 advantage，偏差换方差；REINFORCE 用 Monte Carlo return，无偏但高方差。
4. **PPO 的 clip 为什么有效？** 它限制新旧策略的比率，避免一次更新把策略推到数据分布之外；`min` 让目标对坏方向更悲观，形成软 trust region。
5. **PPO 和 TRPO 的区别？** TRPO 显式约束 KL 散度，求解复杂；PPO 用 clip 近似 trust region，实现简单、效果好。
6. **On-policy 和 off-policy 的区别？** On-policy 只用当前策略的数据，稳定但样本效率低；Off-policy 可以用旧数据/探索数据，样本效率高但有分布偏移。
7. **GAE 的 λ 怎么影响偏差和方差？** `λ=0` 是 TD，偏差大、方差小；`λ=1` 是 Monte Carlo，无偏、方差大；中间值做 trade-off。
8. **RL 在机器人上为什么难？** 样本复杂度高、真实机器人昂贵、sim-to-real gap、奖励设计难、安全约束强；所以模仿学习、离线 RL、model-based RL 很常见。

### 🎤 面试题与答案

**Q1：推导策略梯度。**

A：`J(θ) = E_{τ~π_θ}[R(τ)]`。对 `π_θ` 求导，用 `∇π = π ∇log π`，得到 `∇J = E[Σ_t ∇log π_θ(a_t|s_t) G_t]`。直观上：让高 return 的动作概率上升，低 return 的动作概率下降。

**Q2：解释 PPO 的 clipped objective。**

A：`r_t = π_θ/π_old`，目标 `min(r_t A_t, clip(r_t, 1-ε, 1+ε) A_t)`。当 advantage 为正，比率超过 `1+ε` 后不再奖励；当 advantage 为负，比率低于 `1-ε` 后不再惩罚。`min` 保证目标不会因为比率过大而过度乐观，从而限制策略更新幅度。

**Q3：GAE 是什么？**

A：广义优势估计。`δ_t = r_t + γV(s_{t+1}) - V(s_t)`，`A_t = δ_t + γλδ_{t+1} + ...`。`λ` 控制偏差-方差：`λ=0` 接近 TD，`λ=1` 接近 Monte Carlo。它比单步 TD 更平滑，比完整 return 方差更低。

**Q4：On-policy 和 off-policy 的区别？**

A：On-policy 用当前策略采样的数据更新当前策略，样本不能复用，稳定但样本效率低（PPO、REINFORCE）；Off-policy 可以用旧策略或探索策略的数据，样本效率高，但需要重要性采样或 Q-learning 来处理分布偏移（DQN、SAC）。

**Q5：PPO 和 SAC 怎么选？**

A：PPO 是 on-policy，稳定、易调、适合并行采样和大规模训练；SAC 是 off-policy，样本效率高、适合连续控制和真实机器人场景，但实现和调参更复杂。算力充足、仿真并行选 PPO；样本昂贵、需要复用选 SAC。

**Q6：为什么 RL 在机器人上难落地？**

A：真实交互成本高、样本效率低；仿真到现实的 gap；奖励函数难设计；安全约束；部分可观测；多模态演示。实践上常用模仿学习、离线 RL、model-based RL、sim-to-real 组合。

**Q7：REINFORCE 和 Actor-Critic 的区别？**

A：REINFORCE 用 Monte Carlo return 估计 advantage，无偏但方差大；Actor-Critic 用 critic 估计 value/advantage，方差小但有偏差。Actor-Critic 通常样本效率更高，但需要同时训练两个网络。

**Q8：entropy bonus 的作用？**

A：在损失里加策略熵的奖励，鼓励探索、防止策略过早坍缩到确定性动作；系数太大会导致策略过于随机，太小则探索不足。PPO/SAC 都常用。

# EMA
class EMA:
    def __init__(self, model, decay=0.999):
        self.decay = decay
        self.shadow = {k: v.detach().clone() for k, v in model.state_dict().items()}

    def update(self, model):
        for k, v in model.state_dict().items():
            if v.dtype.is_floating_point:
                self.shadow[k].mul_(self.decay).add_(v.detach(), alpha=1 - self.decay)
            else:
                self.shadow[k] = v.detach().clone()

# 动作平滑
def smooth_action(prev, cur, alpha=0.8):
    return alpha * prev + (1 - alpha) * cur

### 🧠 深度问题

1. **为什么要梯度裁剪？** 防止梯度爆炸导致参数一步更新过大、loss 飞掉；在 RNN、Transformer、RL 中尤其常见。裁剪看范数，不是逐元素截断。
2. **EMA 为什么能稳定训练/提升泛化？** 对权重做时间平均，平滑掉单步噪声，相当于一个廉价的集成；评估时用 EMA 权重通常更稳。注意 EMA 的偏差修正和 BatchNorm buffer。
3. **动作平滑的代价是什么？** 平滑会引入延迟、降低响应速度；过度平滑会跟不上快速变化，导致跟踪误差。要在平滑度和跟踪精度之间调。
4. **Temporal ensemble 和简单滑动平均的区别？** Temporal ensemble 利用重叠动作块的预测，按时间指数加权；滑动平均只作用于已执行动作。前者更平滑，但需要维护动作块队列。
5. **训练不稳定有哪些常见原因？** 学习率过大、梯度爆炸、数据分布突变、数值精度（fp16）、损失尺度、BatchNorm 统计量、优化器状态、初始化。
6. **如何系统排查 loss spike？** 看梯度范数、参数范数、激活值、损失分量；二分定位数据/模型/优化器；先降 LR、加 clip、加 warmup，再查数据。
7. **怎么评估一个策略是否真的更好？** 多种子、固定评估协议、置信区间、成功率和鲁棒性；不要只看单次最优结果，避免 cherry-picking。
8. **EMA 和 BatchNorm 一起用要注意什么？** EMA 只平均了权重，BN 的 running mean/var 也要同步更新，否则训练和评估的统计量不一致；可以 EMA buffer 或在训练集上重新校准。

### 🎤 面试题与答案

**Q1：为什么梯度裁剪要在 optimizer step 之前？**

A：裁剪的是当前 batch 反传得到的梯度；如果先 step，参数已经更新，裁剪就失去意义。标准顺序是 `loss.backward()` → `clip_grad_norm_()` → `optimizer.step()`。

**Q2：EMA 的公式和实现要点？**

A：`θ_ema = decay · θ_ema + (1 - decay) · θ`。训练每一步更新；评估时用 EMA 权重。要点：只平均浮点参数；BN buffer 单独处理；初始化时直接复制模型；decay 通常 0.999 或 0.9999，训练初期可以做 bias correction。

**Q3：动作平滑有哪些方法？**

A：滑动平均（指数或窗口）、低通滤波（一阶/二阶 IIR）、temporal ensemble（重叠动作块加权）、样条/轨迹优化。选择取决于控制频率、动作块长度、对延迟的容忍度。

**Q4：训练出现 loss spike，你怎么排查？**

A：先看梯度范数和参数范数，判断是不是梯度爆炸；再查学习率、warmup、混合精度 loss scale；然后查数据（异常样本、分布突变）和损失各项。应急手段：降 LR、梯度裁剪、warmup、恢复 checkpoint；根因可能是初始化、归一化、数值精度或数据 bug。

**Q5：如何可靠地评估一个策略？**

A：固定评估环境、多个随机种子、足够多的 rollout、报告均值和置信区间；区分训练/验证/测试任务；看成功率、鲁棒性、恢复能力；不要只报最好一次。对真实机器人还要考虑不同初始状态和物体摆放。

**Q6：EMA 和 BatchNorm 一起用会有什么问题？**

A：EMA 只更新权重，不自动更新 BN 的 running statistics；评估时 EMA 权重和旧的 BN 统计量不匹配，可能导致性能下降。解决：把 BN buffer 也做 EMA，或者在训练数据上重新估计 BN 统计量。

**Q7：训练 loop 里你会记录哪些指标？**

A：总损失及各分项、学习率、梯度范数、参数范数、吞吐、显存、训练/验证成功率、动作平滑度、探索熵、value loss、KL/ratio（PPO）。指标要能区分“优化问题”和“数据问题”。

## 附录 B：面试表达模板

回答技术问题时，按四步走：

1. **定义**：一句话说清它是什么、解决什么问题。
2. **机制**：核心公式或数据流，讲清输入输出和关键步骤。

示例（LoRA）：

> LoRA 是一种参数高效微调方法，解决大模型全量微调显存和存储成本高的问题。它冻结原权重，学习一个低秩增量 `BA`，参数量从 `dk` 降到 `r(d+k)`。直觉是下游任务的权重更新集中在低维子空间。边界是秩太小会欠拟合，域偏移很大时不如全量微调。
